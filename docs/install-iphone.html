Installation sur iPhone — ajoutez l’app à l’écran d’accueil.

Sur iPhone (Safari)

  1. Appuyez sur le bouton Ouvrir CofiPointe ci‑dessous.
  2. Touchez le bouton Partager ⇧□ en bas de Safari.
  3. Choisissez Sur l’écran d’accueil.
  4. Validez avec Ajouter.
Ouvrir CofiPointe

Apple n’autorise pas l’installation d’un fichier APK. Cette version web s’installe sur l’écran d’accueil comme une app. Scan QR : caméra arrière pour le pointage.
